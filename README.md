# Лабораторна робота №4 — Layered Architecture (Java)

Цей проєкт переписаний на **Java (Spring Boot)** і реалізує вебзастосунок з REST API за патерном багаторівневої архітектури.

## Обрана предметна область

Система керування задачами (Task Manager).

## Структура шарів

- `presentation` — REST-контролери, DTO, обробка помилок HTTP.
- `application` — бізнес-логіка сценаріїв (`TaskService`).
- `domain` — сутності, enum статусів, інтерфейс репозиторію, доменні винятки.
- `data` — інфраструктурна реалізація репозиторію (`InMemoryTaskRepository`).

## 5 реалізованих сценаріїв

1. **Створити задачу** — `POST /tasks`
2. **Отримати задачу за id** — `GET /tasks/{id}`
3. **Оновити статус задачі** — `PATCH /tasks/{id}/status`
4. **Отримати список задач з фільтром за статусом** — `GET /tasks?status=IN_PROGRESS`
5. **Видалити задачу** — `DELETE /tasks/{id}`

## Атрибути якості

### 1) Модифікованість
- Залежність бізнес-логіки від абстракції `TaskRepository`.
- Можна замінити in-memory реалізацію на БД без змін `TaskService`.

### 2) Тестованість
- API покрито інтеграційними тестами (`MockMvc`) у `TaskControllerTest`.
- Шари ізольовані, що спрощує unit/integration тестування.

### 3) Надійність
- Валідація запитів через `jakarta.validation`.
- Контрольовані відповіді на помилки (400/404) через `GlobalExceptionHandler`.

### 4) Зрозумілість/підтримуваність
- Код розділено по шарах з чіткими відповідальностями.
- Імена методів та класів відповідають use-case сценаріям.
